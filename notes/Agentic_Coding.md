# Agentic Coding

**Summary**: Notes on agentic workflows, coding agents, and patterns for LLM agents that build and maintain knowledge or code over time.
**Last updated**: 2026-10-03

---

- [LLM-Wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f): Andrej Karpathy's write-up on a persistent, compounding knowledge base pattern — raw sources, an LLM-maintained markdown wiki, and a schema doc (like `CLAUDE.md`) defining ingest/query/lint workflows, built on Obsidian plus git. Keywords: LLM wiki, personal knowledge base, agent workflow, Obsidian, markdown, Karpathy
- [Karpathy's LLM Wiki - Full Beginner Setup Guide](https://www.youtube.com/watch?v=iXd0t60YmMw): Video walkthrough for setting up the LLM-Wiki pattern from scratch end to end. Keywords: video tutorial, setup guide, LLM wiki, knowledge base, Obsidian
- [OpenKnowledge](https://openknowledge.ai/): Open-source, AI-native markdown editor positioned as an alternative to Obsidian for building knowledge bases and agent "second brains," with a [built-in template](https://openknowledge.ai/docs/workflows/karpathy-llm-wiki) for the Karpathy LLM-Wiki workflow. Keywords: markdown editor, open-source, AI-native, knowledge base, agent, Obsidian alternative
